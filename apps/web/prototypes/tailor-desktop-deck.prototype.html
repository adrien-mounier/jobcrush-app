#157 · Design B round 3c — desktop deck, the CV beside it

The same job, the same eight asks, the same physics as tailor-merged.prototype.html — but the OTHER interaction model: one card at a time instead of a persistent list. Everything else is now matched to the chosen desktop file exactly: same app width, same column ratio, same CV size. The single variable left is the one being judged.

What changed since you last saw this (your two notes): it is no longer a 640px window floating on a desktop — it fills the page like a real product · and the CV is no longer hidden behind a pull-up sheet, it sits on the right, always visible. The drag mechanic is gone entirely; it existed only because a phone has no room to show a question and a document at once.

New in 3c (your note): the progress bar now opens. Click it and the eight things this advert asks for are listed underneath, marked you have this / expired / not yet, and each satisfied one opens to show the evidence — the same words the list version uses. It only reports. Nothing in it can be answered: an unanswered ask is not even clickable, because the cards are where answering happens.

The gain that came free: because the CV is always on screen, you now watch each answer write itself onto your CV — that effect existed in both earlier files but was hidden behind a closed sheet unless you happened to open it first.

The ending: answer the last card and press Continue — it settles downward rather than sliding away, a pulse travels to the CV, the page answers with one ring and a single line, then the two exits arrive.
