The card we keep, and the job's own screen built from it

The existing design is reused, not replaced. Both panels run the shipped deck.css and the shipped card markup, so every difference you can see below is a difference we are proposing — there is nothing else going on.

Two changes: an apply here row under the title, and the primary button reads Write the tailored CV. The switch shows what the apply row does when the advert carries no link — which is normal for a pasted job, and is what keeps the application report able to send you anywhere.

The middle panel is the chosen one. On every panel, “Read the ad in full” now sits directly under the title — on the deck card too, which is the one change that lands on both screens.

The third panel answers a separate question: what the same screen looks like if the checklist takes the place of the four-cell match breakdown. It replaces the fit / not-yet lists as well, because it already contains them — keeping both would print the same ten requirements twice.

Why the button changes on one screen and not the other

On the deck, “I want this one” pairs with “Not for me” and matches the stamp you see when you drag the card right — “Want it”. It is a preference, not a commitment. On the job's own screen there is nothing to reject, the press is the commitment, and “Write the tailored CV” says what happens next.

The job description moves up — on both screens

It sat at the foot of the card, under everything the machine had to say about you. A job description belongs with the job, so it now follows the title and subtitle directly. Its existing hairline reads as the header's closing rule rather than as a footer separator, so the move needed no restyling. Opened, the advert text lands exactly where you would look for it.

Why the apply link is not on the deck

The deck card is swiped, so a link inside it fights the gesture. And putting “apply here” in front of you mid-triage invites you to leave for the job board before we have written you a better CV — the opposite of what the deck is for.

Why the empty state is a control, not a caption

A pasted advert may carry no link — the paste door never blocks on one. The application report puts the apply link at the top, so a job with no link leaves a hole in the one document you read right before applying. “Add the application link” closes it in one tap, at the moment you are looking at the job.

What the third panel costs and buys

Buys: the requirement each fact answered, the sentence behind the verdict, and the Essential / Desirable weight — so a missing essential reads differently from a missing nice-to-have.

Costs: measured, not guessed — the card goes from 960px to 1208px, so about a quarter taller, not double. And the plain-word verdict “Strong” leaves with the breakdown grid unless it moves beside the ring.

One thing it inherits, worth a decision: the card mutes the text of a “where you don't — yet” row, which is right on a card you skim. Here it makes the one line you most need to read the faintest on the screen. Left as the card ships, because that is what reuse means — say the word and the gap row keeps full-strength text.
