## Anti-Patterns Verdict

Not AI slop — the opposite failure: absence of design. Trope checklist clean (no side-stripes, gradient text, glass, hero metrics, eyebrows, numbered scaffolding). Deterministic scan: 0 findings across 10 files. The product's own design language (evidence-badge palette `--jc-verified/derived/partial/suggested` in tokens.css) and the fetched `DeckClaim.classification` / `TraceEntry.classifications` data are never rendered — the differentiator exists in code and never reaches the screen. Zero brand presence: no header, logo, or wordmark on any screen (only the tab title). Screenshot pass: primary `.btn` on first paint (disabled, opacity 0.5) reads as washed-out/disabled-looking sage; signup email input is unstyled native (globals.css:81 styles only `input[type="text"], textarea`; the field is `type="email"`).

## Priority Issues

- **[P0] Magic link opened in another browser orphans the session** (auth/verify/page.tsx:14-27). Resume depends on this browser's localStorage + cookie; Gmail/Outlook in-app browsers (the common mobile path) have neither → user lands on /import with everything gone. Fix: encode jobId in the link server-side; on verify, look up the user's pending job from the server. → /impeccable harden
- **[P1] Email typo is a dead end** (signup/page.tsx:80-92). `sent` is terminal; no "wrong address?" or resend. Fix: text button resetting `sent`, keep the email in the field. → /impeccable harden
- **[P1] Deck batch state is fragile** (deck/[jobId]/page.tsx:30,34,107-108). Batch toggles + grill answers are local state (refresh loses them); commit fires N sequential POSTs behind "Working…", half-committing on mid-loop failure. Fix: persist batch toggles per tap (endpoints exist) — dissolves the loop. → /impeccable harden
- **[P1] The ending under-delivers the product's promise.** `result.rootCv.markdown` (api.ts:112) is never rendered — the final screen shows trace bullets with tiny "fix" links; the preview's watermark promise is never resolved; no download, no next step; classification badges never shown. Fix: render the markdown as a document (same frame as preview), badge lines with the evidence palette, end with an explicit next action. → /impeccable shape + colorize
- **[P2] Signup wall is a surprise + copy confusion.** Preview CTA "Confirm my facts" gives no hint of an email gate; "Verify your email to unlock your draft" confuses (user just saw the draft). Fix: one line under the CTA ("takes an email, no password"); rewrite the signup h1. → /impeccable clarify
- **[P2] Unstyled email input at the highest-stakes conversion moment.** Add `input[type="email"]` to the globals selector. → /impeccable polish
- **[P2] Interactive-state matrix is default/disabled only.** No :hover/:active on .btn or .chip, no authored :focus styles anywhere; disabled = opacity 0.5 makes first-paint primary CTAs look broken. → /impeccable polish

## Minor Observations

- "it stays on your device session only" (import lede) is untrue — the file is uploaded; trust liability.
- Duplicate target titles not case-folded (chip + typed variant both sent).
- Inline style={{}} spacing bypasses the token scale throughout pages.
- Error copy casing inconsistent ("something went wrong" vs sentence case).
- Preview: two sequential fetches; "preview not ready yet" is terminal, no retry/poll.
- suppressHydrationWarning papers over the timer SSR mismatch; move timer client-side with setInterval.
- Bad jobId on deck renders raw error full-screen; no friendly not-found.
- "Remove this line" sits next to "Cancel" with identical secondary styling in the fix editor.
- Headline wraps "…in about 2 / minutes." — add text-wrap: balance to headings.
- Good details: type="email" keyboard, thorough file accept list, aria-hidden Google SVG, honest coming-soon demand capture.

## What's Working

1. SSE progress feed of real mined facts — best-in-class wait design; converts the scariest moment into the trust-building one.
2. Microcopy with an actual voice ("we never guess at those"; "noted that you want it"; "skip anything you'd rather not").
3. Coherent trust architecture: value before wall, source quotes under claims, fix-the-fact-not-the-text with rebuild, no freeform editor.

## Questions to Consider

1. What if the deck WAS the preview — confirm claims by tapping lines of the rendered draft, watermark dissolving as facts confirm?
2. What if the email ask moved into the progress wait — captive positive attention, and the magic link could carry the job (fixes the P0)?
3. What if the ending gave back the tailored draft for the posting they came for, plus "your roles match N more live postings" (the S3 front door)?
